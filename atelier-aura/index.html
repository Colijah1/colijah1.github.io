The maison

Atelier Aura began as a student web project about a personal obsession: fragrance. This redesign imagines it as a full maison built for the Gulf, where oud sits beside jasmine and every bottle has to survive a 45°C afternoon.

Each page answers the questions people ask at a perfume counter: how it opens, how it dries down, how long it lasts and when to wear it.
